# A Radon–Nikodým Perspective to Anomaly Detection

This github repository comprises the following folders:
1. Algorithms : Contains codes for baselines we use for comparison
2. Datasets : Some datasets that can be utilised for reproducing results

Main Data Sheet contains the following sheets:
Multivariate and Univariate: (All baselines and with individual sheets for comparison with newer SoTA)
Precision 
Recall
F-1 Score
AUC-ROC
Original v/s the modified algorithms using RN-Loss

The file RN_Net.py contains the code for running the model RN-Net.

The paper can be found here: https://arxiv.org/abs/2502.18002
